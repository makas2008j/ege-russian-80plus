ЕГЭ Русский 80+ — версия с журналом ошибок.

Запуск Windows:
1. Откройте PowerShell в этой папке.
2. Выполните: py -m http.server 8080
3. На ПК: http://localhost:8080
4. На iPhone в той же Wi‑Fi сети: http://IP_КОМПЬЮТЕРА:8080

Если видите старую версию: закройте вкладку, остановите сервер Ctrl+C, снова запустите его из этой папки и откройте адрес заново.
